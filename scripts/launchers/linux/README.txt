Data Recover Free — Linux
=====================

How to run
----------
1. Extract: `tar -xzf datarecoverfree-linux.tar.gz`
2. Run:    `./datarecoverfree.sh`
   - The script opens `web/index.html` in your default browser via xdg-open.
   - You can also open `web/index.html` manually.

Optional: install as a desktop app
----------------------------------
With the page open in Google Chrome or Chromium, click the install icon in
the address bar (or "Install Data Recover Free..." in the menu) to add it to
your application launcher and run it offline.

Privacy
-------
Any file you open never leaves your computer; all processing happens locally
in the browser.
