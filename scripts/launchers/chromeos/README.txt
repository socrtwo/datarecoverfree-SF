Data Recover Free — ChromeOS
========================

How to run (recommended)
------------------------
Data Recover Free is a Progressive Web App (PWA) and runs natively on ChromeOS.

1. Open Chrome and navigate to the hosted version:
     https://socrtwo.github.io/datarecoverfree-SF/
2. Click the install icon in the address bar (a downward arrow + monitor),
   or open the menu -> Install Data Recover Free...
3. The app appears in your launcher and works fully offline after first run.

Run from this archive (offline, no internet)
--------------------------------------------
1. Extract this archive to your Files app (e.g., to "My files / Data Recover Free").
2. Right-click `web/index.html` -> Open with -> Chrome.
3. Use the install icon to pin it to your launcher.

Privacy
-------
Any file you open never leaves your Chromebook; all processing happens locally
in the browser.
